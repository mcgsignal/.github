# Security policy

This policy is for the repositories of this organization and for mcgsignal.com.

## Report a security problem

Do not open a public issue for a security problem. Use one of these two ways:

1. On the repository, open **Security**, then **Report a vulnerability**. Only the maintainers can read the report.
2. Send an email to developers@mcgsignal.com.

Tell us what you found, where you found it, and the steps that show the problem. We answer within 5 working days. Give us time to correct the problem before you tell other people.

## A wrong value is not a security problem

To report a wrong value in our data, use the "Data error" form in the [methodology](https://github.com/mcgsignal/methodology) repository.
