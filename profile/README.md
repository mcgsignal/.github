# MCG Signal

Project-level data on Robinhood Chain, for people and AI agents. Founder and project interviews by MCG Live.

## What is live

| Page | What it shows | Where the data comes from |
| --- | --- | --- |
| [The Feed](https://mcgsignal.com/) | Founder and project interviews from MCG Live: one page for each project on each show. Each claim shows its time in the interview. | The interview on MCG Live. |
| [Burn Tracker](https://mcgsignal.com/burn) | The burns of Robinhood Chain tokens, over the period you choose. | Our own nodes. |
| [Protocol activity](https://mcgsignal.com/feed/mcg-2026-10-27/0xc72f232a6869e6cf34dc06129affd07f8a2a246a#protocol) | On the page of a project: the volume, the fees and the trades of its protocol. Mancer is the first example. | The statistics that the project publishes, read one time each day. |

Our on-chain data starts with Robinhood Chain. The interviews also cover projects on Solana, Base, Ethereum, NEAR and other chains.

## Data for apps and AI agents

These links open data files, not pages.

| File | What it holds |
| --- | --- |
| [Token list (JSON)](https://icm-analytics.com/label/v1/tokenlist.json) | The name, ticker and logo of each token, listed by its contract address. |
| [llms.txt (text)](https://mcgsignal.com/llms.txt) | A map of the site: each interview with a summary of one line. |
| [Sitemap (XML)](https://mcgsignal.com/sitemap.xml) | The address of each page. |
